# Pal

Pal 是一款 macOS 阅读与学习搭子应用。这里提供**不含开发者个人数据的试用安装包**、更新包、使用说明及问题反馈入口。当前版本 **0.8.4**，支持 **Apple Silicon Mac**。

- **已安装 0.8.3：** [Pal 0.8.4 更新包 · 更新器修正版 2](https://github.com/Wilsongogogo/Pal/releases/download/v0.8.4/Pal-0.8.4-update-fix2-mac-arm64.zip)

完整试用版首次打开为空白资料库，默认名称 Pal / Buddy，不附带开发者的文件、笔记、聊天、头像、AI 账户或密码。AI 功能需配置自己的模型连接或账户；未连接时仍可本地阅读。

## 开始使用

1. 解压完整安装包，把 **Pal.app** 放入“应用程序”或自己的 Applications 文件夹，打开应用。
2. 导入课件或电子书，也可拖到侧栏课程或文件夹。
3. 在头像／学习空间菜单的设置中连接自己的 AI。指向读取与跨应用截图需要按提示授予当前应用所需的系统权限。
4. **⌘K** 搜索；方向键默认直接定位。沉浸阅读中按 **⌘⇧B** 调出右侧 standby。

更新已有 0.8.3：退出 Pal（⌘Q），完整解压更新包，双击 **“更新 Pal.command”**，再拖入原来的应用。应用改名为 **Pal 2.app** 也可以。更新器会保留原来的资料库与连接，区分个人版和试用版，并备份旧应用资源。

## 可以做什么

- 阅读 PDF、PPT/PPTX、EPUB、TXT、Markdown、Word 等资料。PPT 在本机转为静态页面，保留原件。
- 圈画、高亮、摘录、批注、提问，结合原文继续 AI 问答；保存笔记与学习历史。
- 用 standby 整理章节和全书脉络，暂停后继续；整理时仍可浏览章节。
- 用文件夹和拖动排序组织课程与书架，按来源浏览复习材料。
- 联结电子书或课件中的概念、难点与摘录，保存并导出思维导图、关系图、层级图或流程图。
- 搜索全文与笔记，向 AI 询问 Pal 的操作方法；使用翻译、生词本、复习卡、日程和计时等功能。

## 目前的局限

这是试用版本，欢迎帮助打磨。

- PPT 为**静态阅读**，不会播放动画、视频或演示过渡；缺失字体与复杂对象可能出现排版差异，请与原文件核对。
- 扫描页、复杂排版、损坏、加密及 DRM 文件可能无法完整提取；部分格式依赖随包提供的本机转换组件。
- AI 需要自己的连接与额度，受网络和服务商影响；回答、关系建议及图示层级可能出错，请核对原文。部分服务不提供准确的剩余额度。
- macOS 窗口动画与玻璃效果仍在改进。目前只提供 Apple Silicon 安装包，尚未完成 Apple 开发者公证，系统可能提示未知开发者。请从本仓库下载，不要关闭系统安全防护。

## 反馈 Bug 和功能建议

请到 [Issues](https://github.com/Wilsongogogo/Pal/issues) 提交反馈。

**Bug：** 请注明 Pal 版本、macOS 版本／芯片、复现步骤、预期和实际结果，尽量附截图或录屏。先遮盖私人资料、账户、密码和密钥。

**功能建议：** 请说明想解决什么问题、典型使用场景，以及目前如何绕过这个问题。具体、坦诚的反馈会直接帮助确定下一步改进。
